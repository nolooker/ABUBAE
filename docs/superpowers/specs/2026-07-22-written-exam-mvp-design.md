# 정보처리기사 필기 무료 MVP 설계

## 목표

로그인하지 않은 사용자도 정보처리기사 필기 최근 5개년 기출문제를 회차 단위로 풀고, 회차 종료 후 일괄 채점 결과와 아부배식 해설을 확인할 수 있게 한다.

## 콘텐츠 범위

- 자격증: 정보처리기사
- 시험 유형: 필기
- 시험 연도: 2021년부터 2025년까지
- 시험 회차: 해당 연도에 실제 데이터가 확보된 회차
- 초기 입력 자료: 2021년 1회, 2회, 3회 PDF
- 문제 형식: 객관식 4지선다

2026년 시험은 모든 회차가 끝나고 원본 자료가 확보된 뒤 별도 콘텐츠 업데이트로 추가한다. 정보처리기사 실기와 다른 자격증은 이번 MVP에서 제외한다.

## 이용 정책

- 모든 필기 회차는 로그인 없이 무료로 이용할 수 있다.
- 풀이 답안과 결과는 React 메모리에만 유지한다.
- 서버, 쿠키, `localStorage`, `sessionStorage`, IndexedDB에 비회원 풀이 기록을 저장하지 않는다.
- 새로고침하거나 페이지를 나가면 진행 상황과 결과가 사라진다.
- 회원가입, 로그인, 풀이 이력, 오답노트 저장, 즐겨찾기, 이어 풀기는 이번 MVP의 완료 조건에 포함하지 않는다.
- 기존 회원가입과 로그인 경로는 삭제하지 않지만, 기출문제 이용을 위해 로그인을 요구하지 않는다.

## 사용자 흐름

1. 사용자가 정보처리기사 학습 허브에 들어간다.
2. `필기` 영역을 선택한다.
3. 2021~2025년 중 데이터가 존재하는 연도와 회차를 선택한다.
4. 회차의 첫 문제부터 풀이를 시작한다.
5. 답안을 선택하고 이전·다음 문제 또는 문제 번호표로 이동한다.
6. 풀이 중에는 정답과 해설을 보여주지 않는다.
7. 사용자가 `최종 제출`을 누른다.
8. 미응답 문제가 있으면 개수와 문제 번호를 알리고 계속 풀기 또는 제출을 선택하게 한다.
9. 제출을 선택하면 미응답을 오답으로 포함해 전체 회차를 일괄 채점한다.
10. 결과 화면에서 점수, 정답률, 과목별 결과, 문제별 정답과 해설을 확인한다.
11. 사용자는 오답 문제만 보거나 같은 회차를 처음부터 다시 풀 수 있다.

## 화면 설계

### 연도·회차 선택

- 연도별로 실제 데이터가 있는 회차만 표시한다.
- 각 회차 카드에 총 문제 수와 과목 수를 표시한다.
- 데이터가 없거나 공개 준비가 끝나지 않은 회차는 표시하지 않는다.
- `풀기` 버튼으로 회차 풀이 화면에 진입한다.

### 회차 풀이

- 상단에 `2021년 1회 정보처리기사 필기`처럼 현재 회차를 표시한다.
- 현재 문제 번호, 전체 문제 수, 답변 수, 미응답 수를 표시한다.
- 문제 본문과 네 개의 선택지를 제공한다.
- 사용자는 제출 전까지 선택 답안을 자유롭게 변경할 수 있다.
- 이전·다음 버튼과 문제 번호표로 문제를 이동한다.
- 문제 번호표는 현재 문제, 답변 완료, 미응답 상태를 구분한다.
- 표나 그림이 필요한 문제는 선명한 전용 이미지와 대체 텍스트를 표시한다.
- 풀이 도중에는 정답 강조, 정답 문구, 해설을 렌더링하지 않는다.

### 제출 경고

- 모든 문제에 답했으면 확인 대화상자를 표시한다.
- 미응답 문제가 있으면 `미응답 3문제: 12, 44, 78번`처럼 구체적으로 안내한다.
- 사용자는 `계속 풀기`와 `미응답을 오답 처리하고 제출` 중 하나를 선택한다.
- 제출 후에는 현재 답안을 수정할 수 없다.

### 회차 결과

- 100점 환산 점수
- 전체 문제 수
- 정답, 오답, 미응답 문제 수
- 전체 정답률
- 과목별 정답 수와 정답률
- 문제별 내 답안, 정답, 아부배 해설
- 오답과 미응답 문제만 보기
- 회차 다시 풀기
- `이 결과는 저장되지 않습니다` 안내

## 채점 규칙

- 객관식 선택 번호가 정답 번호와 같으면 정답이다.
- 선택하지 않은 문제는 미응답이자 오답으로 계산한다.
- 점수는 `정답 수 / 전체 공개 문제 수 × 100`으로 계산하고 소수 첫째 자리에서 반올림한다.
- 과목별 정답률은 해당 과목의 공개 문제만 분모로 사용한다.
- 불완전한 데이터로 인해 제외된 문제는 점수 분모에도 포함하지 않는다.
- 채점 계산은 순수 함수로 구현해 브라우저와 테스트에서 동일한 규칙을 사용한다.

## 데이터 구조

### ExamRound

```ts
type ExamRound = {
  examSlug: 'jeongchogi'
  examType: 'written'
  year: number
  round: number
  title: string
  questionCount: number
  subjects: string[]
  isPublished: boolean
}
```

### WrittenQuestion

```ts
type WrittenQuestion = {
  id: string
  examSlug: 'jeongchogi'
  examType: 'written'
  year: number
  round: number
  subject: string
  number: number
  content: string
  choices: [string, string, string, string]
  answerIndex: 0 | 1 | 2 | 3
  explanation: {
    summary: string
    choiceNotes: [string, string, string, string]
    keyPoint: string
    memoryTip?: string
  }
  asset?: {
    src: string
    alt: string
  }
  sourceLabel: string
  reviewed: boolean
  published: boolean
}
```

`reviewed`와 `published`가 모두 `true`인 문제만 사용자에게 제공한다. ID는 `jeongchogi-written-2021-1-001` 형식으로 생성한다.

## PDF 콘텐츠 처리

사용자는 제공된 2021년 1·2·3회 PDF에 대해 아부배 웹사이트 게시, 상업적 이용, 문제·선택지 추출과 재편집, 해설의 수정·신규 작성, Supabase 저장과 사용자 제공을 포함한 허락을 받았다고 확인했다. 허락 증빙은 사용자가 별도로 보관한다.

처리 순서:

1. PDF별 페이지 수와 텍스트 추출 상태를 확인한다.
2. 문제 번호, 본문, 선택지 네 개, 정답을 구조화한다.
3. 과목 경계를 문제 번호와 PDF 제목으로 교차 확인한다.
4. 표, 코드, 그림이 있는 문제를 별도 검수 목록으로 분류한다.
5. 누락 번호, 중복 번호, 선택지 부족, 정답 범위 오류를 자동 검사한다.
6. 문제와 정답을 사람이 원본 PDF와 대조한다.
7. 아부배식 해설을 새로 작성한다.
8. 해설과 선택지 사실관계를 검수한다.
9. 검수 완료 데이터만 JSON과 Supabase seed SQL로 생성한다.
10. 개발 화면에서 회차별 문제 수와 채점 결과를 재검증한다.

원본 PDF의 디자인, 로고, 캐릭터, 워터마크, 기존 해설 문장은 사이트에 복제하지 않는다. 표나 그림 문제는 필요한 정보만 권리 범위 안에서 아부배 스타일의 새 자산으로 재작성한다.

## 아부배 해설 기준

각 해설은 다음 순서를 따른다.

1. 정답: 선택지 번호와 정답 문구
2. 핵심 해설: 비전공자가 이해할 수 있는 2~4문장
3. 오답 분석: 네 선택지 각각의 정답 또는 오답 이유
4. 시험 핵심 포인트: 시험장에서 기억할 한 문장
5. 암기 팁: 도움이 되는 문제에만 제공

작성 원칙:

- PDF의 기존 해설 문장을 복사하지 않는다.
- 전문 용어는 쉬운 말로 먼저 설명한 뒤 정확한 용어를 연결한다.
- 정답 선택지만 설명하지 않고 오답 선택지도 검토한다.
- 과도하게 긴 이론 설명은 피한다.
- 기술 버전이나 표준에 따라 달라지는 내용은 문제 출제 시점의 기준을 밝힌다.
- 사실 확인이 끝나지 않은 해설은 `reviewed: false`로 유지해 공개하지 않는다.

## 오류 처리

- 존재하지 않는 연도·회차는 브랜드 404 화면을 표시한다.
- 공개 가능한 문제가 0개인 회차는 회차 목록에서 제외한다.
- 선택지가 네 개가 아니거나 정답 번호가 잘못된 문제는 빌드 검증에서 실패시킨다.
- 표·그림 자산이 누락된 문제는 공개하지 않는다.
- 제출 직전 발생한 렌더링 오류는 현재 선택 답안을 보존한 오류 화면으로 안내한다.
- 새로고침이나 외부 이동 시 저장되지 않은 답안이 사라진다는 브라우저 이탈 경고를 제공한다.

## 테스트 기준

- 2021~2025년 중 공개 데이터가 있는 회차만 목록에 나타난다.
- 제출 전에는 정답과 해설이 DOM에 존재하지 않는다.
- 답안을 선택하고 문제 사이를 이동해도 같은 세션에서 선택이 유지된다.
- 미응답 문제 번호가 제출 경고에 정확히 표시된다.
- 경고 후 제출하면 미응답이 오답으로 계산된다.
- 점수와 과목별 정답률이 고정된 테스트 데이터의 예상값과 일치한다.
- 결과에서 내 답안, 정답, 해설이 정확히 표시된다.
- 오답만 보기와 다시 풀기가 정상 동작한다.
- 새로고침 후 이전 결과가 복원되지 않는다.
- 잘못된 회차 주소와 불완전한 문제 데이터가 사용자 화면에 노출되지 않는다.
- 모바일 화면에서 문제, 선택지, 문제 번호표, 제출 대화상자를 사용할 수 있다.

## MVP 제외 범위

- 정보처리기사 실기
- SQLD와 기타 자격증
- 회원 풀이 기록과 동기화
- 저장형 오답노트
- 즐겨찾기와 이어 풀기
- 무료 PDF 다운로드
- 결제와 프리미엄 콘텐츠
- 관리자 콘텐츠 편집 화면
- 2026년 기출문제
