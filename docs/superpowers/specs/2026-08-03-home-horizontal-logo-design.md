# 홈 가로형 로고 적용 디자인

## 목표

홈 페이지 전용 푸터에 현재 세로형 로고 대신 A안 가로형 로고를 표시한다.

## 변경 범위

- `src/app/page.tsx`의 홈 전용 푸터 이미지 경로를 `/images/brand/abubae-logo-horizontal-balanced.png`로 변경한다.
- 원본 이미지의 1915:821 비율을 반영한 `width`와 `height`를 지정한다.
- 데스크톱에서 약 300px, 작은 화면에서는 컨테이너 너비를 넘지 않도록 표시한다.
- 중복되는 푸터 문구는 유지하여 이번 변경을 이미지 교체로만 제한한다.

## 비변경 범위

- `public/images/brand/abubae-logo-primary.png` 원본은 보존한다.
- 공용 `Header`와 `Footer`, 다른 페이지의 로고는 변경하지 않는다.
- A안 PNG 자체는 수정하지 않는다.

## 검증

- 홈 페이지가 A안 파일 경로만 참조하는지 확인한다.
- Next.js 빌드 또는 관련 정적 검사를 실행한다.
- 전체 테스트를 실행해 회귀가 없는지 확인한다.
