## 자동 추출 개선 내역

- PDF의 좌·우 열을 독립적으로 읽은 뒤 실제 독서 순서로 결합했다.
- 페이지가 바뀌면서 본문 또는 선택지가 이어지는 문항을 하나의 문항으로 복원했다.
- `IEEE 802.3`, IP 주소처럼 문항 번호와 비슷한 소수 표기를 문항 경계에서 제외했다.
- 마지막 페이지 정답표에서 단일 정답만 연결하고 복수·전항 정답은 예외로 남겼다.
- 그림으로 배치된 1회 48번과 3회 43번의 표 선택지를 직접 대조한 뒤 접근 가능한 텍스트 행으로 재작성했다.

## 공개 차단 원칙

자동 추출 성공은 내용 검수 완료를 뜻하지 않는다. 선택지 순서, 코드 들여쓰기, 수식, 표 구조, 복수 정답을 사람이 확인하기 전까지 후보 JSON은 공개 데이터나 시드 SQL로 변환하지 않는다.
